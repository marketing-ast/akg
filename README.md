# AKG

Одностраничный mobile-first сайт-визитка магазина женской одежды AKG.

## Техническая основа

- Статичный HTML, CSS и небольшой JavaScript — без сервера, базы данных и оплаты.
- Размещение: GitHub Pages.
- Основные страницы: главная, `/privacy/` (Политика конфиденциальности), `/offer/` (Публичная оферта).
- Дизайн: морской воздух и песчаное побережье Мангистау; палитра из `palitra.jpg` будет использована как исходная, а финальный визуальный язык — по предоставленным референсам и фотографиям.
- Ни факты о магазине, ни юридические реквизиты не добавляются без подтверждения владельца.

## Полученные данные

- Название: AKG, магазин женской одежды.
- Адрес, как предоставлен: «МАНГИСТАУСКАЯ ОБЛАСТЬ, ЖАНАОЗЕН Г.А., Г.ЖАНАОЗЕН».
- Контакты: `+7 700 820 1777`.
- Исходные фотографии: `photos/`.

## До начала дизайна нужны от владельца

1. Короткое описание магазина и материалы, которые должны попасть на сайт.
2. Скриншоты Instagram и Pinterest-референсы — только как визуальный ориентир, не для публикации.
3. Оригиналы фотографий, разрешённых к публикации, и при необходимости подписи к ним.
4. Домен и предпочтение: `www.домен` либо домен без `www` как основной адрес.
5. Публичный адрес в Актау, если он должен отличаться от указанного адреса, а также часы работы — только если их нужно публиковать.
6. Адрес электронной почты для политики конфиденциальности: он обязателен в формулировке об отказе от уведомлений.
7. Для полноценной публичной оферты: точное наименование продавца (ИП/ТОО), БИН/ИИН при необходимости, email и правила покупки/возврата, которые владелец готов опубликовать.

## Публикация на GitHub Pages

После первой версии сайта: в GitHub → **Settings → Pages** выбрать ветку `main` и папку `/ (root)`.
Пользовательский домен добавляется в тех же настройках до внесения DNS-записей у регистратора. HTTPS включается после выпуска сертификата GitHub Pages.
